Project Overview

This project demonstrates a complete beginner-friendly DevOps workflow. The website source code is maintained in GitHub. GitHub Actions automatically builds the Docker image and publishes it to GitHub Container Registry.


The Docker container is then used to run the website locally through port 8080.
